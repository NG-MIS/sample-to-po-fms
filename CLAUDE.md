# Working rules for this project

Read `docs/PROJECT_BIBLE.md` first. It is the single source of truth.

With every change, in the same commit:

1. Update `docs/PROJECT_BIBLE.md` (the affected section, the "Last updated" date, and the change log).
2. Update `docs/PROGRESS.md`.
3. Add a row to `docs/DECISIONS.md` when a choice was made.
4. Move items between `docs/FUTURE.md` and `docs/PROGRESS.md` as they are picked up.
5. Save every database structure change as a dated file in `supabase/migrations`.

How Nihal wants to work:

- One step at a time. Confirm understanding in plain words before building.
- Ask one question at a time.
- Plain language in explanations and in these docs.
- Follow the standing rules for every screen in section 5 of the bible.
